# Unprimed baseline sessions

Observing Claude Code from a normal session is confounded. This operator's
real `$HOME` carries a substantial CLAUDE.md, a must-read knowledge base,
skills, agents, and hooks, all of which shape every response -- and from
inside such a session there is no way to separate what the tool does from
what the configuration made it do.

This repo provides a session where that separation is unambiguous. It is the
place to establish what Claude Code does by default, to reproduce a suspected
bug where no reviewer can dismiss it as a configuration artifact, and to hand
someone else a reproduction they can run without adopting this operator's
setup.

The beneficiary is whoever is investigating Claude Code itself, and
secondarily whoever receives a bug report from them.
