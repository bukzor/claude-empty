# Emptiness is verifiable

That the room is empty is a claim about a specific version of a program that
changes weekly -- not a property of the directory layout. It stays checkable
on demand, by a procedure a future agent can run without first reconstructing
the reasoning that produced it.

An unverifiable cleanroom is worse than none: it yields confident,
contaminated results, and the contamination is invisible precisely because
the room was supposed to prevent it.

This is the goal that obliges every mechanism to have a procedure in
`../../testing.kb/`, and every claim in `../../background.kb/` to name the
version it was established under.
